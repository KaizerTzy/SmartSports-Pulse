## Why these four (and what was cut)

**Kept**

- **배당 계산** — mission + the merged 단폴/다폴 job. One nav slot, two lesson types inside it.  
- **마켓 가이드** — 승무패, Money line, Handicap, Over/Under as separate posts, not four nav items.  
- **유럽 축구** and **야구** — the two “never cut” sports. Split so NBA/롤 cannot hide in a 종목 Misc.

**Placement rule (overlap control)**

- Number → payout, Decimal vs 프로토, single vs parlay, odds multiplying, risk scaling → **배당 계산**  
- What 승무패 / Money line / 핸디캡 / 오버언더 *is* (generic or mock example) → **마켓 가이드**  
- Why *this sport’s* scoring makes that market look the way it does → **유럽 축구** or **야구**  
- If a draft is “핸디캡 -1.5 읽는 법” with a throwaway football example, it is 마켓 가이드. If it is “축구 90분과 핸디캡,” it is 유럽 축구.

**Not launch nav (tag, page, or Phase 2)**

| Idea | Why it is not a Phase 1 category |
|---|---|
| 단폴과 다폴 | **Merged into 배당 계산.** Series/order inside that category, not a fifth slot. |
| 입문 / Start here | **Page** (or a tag) pointing at the first 배당 계산 posts. |
| 프로토 | **Tag** on 배당 계산 posts. Format, not a pillar. |
| 분석 | **Not a nav word.** Would be read as picks. |
| American odds | **After launch set**, as posts inside `odds-math`. Not nav. |
| 농구 (NBA/KBL), 롤 (esports) | **Phase 2.** Out of launch navigation. |
| 전략 | **Phase 2 / out of Phase 1.** |
| 뉴스 / 경기 일정 / live boards | **Out.** Static hub only. Out of launch navigation. |
| About, 19+ footer, 광고 슬롯 | **Chrome / pages.** |
| Tosigi / Global Motorsports / Coverspick / bitcoingame.blog | **Identity references only** (`00-site-references.md`). No 카지노, 슬롯, 비트코인, 예측, or 모터스포츠 nav. |
