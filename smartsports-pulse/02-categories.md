## Why these five (and what was cut)

**Kept**

- **배당 계산** — the mission. If this is not in nav, the site is a definition blog.  
- **단폴과 다폴** — you put this job at the front, *before* Handicap/오버언더. It is a different question (“what happens when I add a second selection?”) than “what does 2.50 pay?” Overlap with 배당 계산 is real; it earns a slot only if you will keep publishing combination-math explainers, not one evergreen page.  
- **마켓 가이드** — four locked lessons (승무패, Money line, Handicap, Over/Under) that are not odds-format math. One category, separate posts. Not four nav items.  
- **유럽 축구** and **야구** — your two “never cut” sports. Split on purpose: a combined 종목 가이드 would be a polite Misc. Names stay specific so NBA/롤 cannot hide here.

**Placement rule (overlap control)**

- Number → payout, Decimal vs 프로토 → **배당 계산**  
- One selection vs several, odds multiplying, risk scaling → **단폴과 다폴**  
- What 승무패 / Money line / 핸디캡 / 오버언더 *is* (generic or mock example) → **마켓 가이드**  
- Why *this sport’s* scoring makes that market look the way it does → **유럽 축구** or **야구**  
- If a draft is “핸디캡 -1.5 읽는 법” with a throwaway football example, it is 마켓 가이드. If it is “축구 90분과 핸디캡,” it is 유럽 축구.

**Not launch nav (tag, page, or Phase 2)**

| Idea | Why it is not a Phase 1 category |
|---|---|
| 입문 / Start here | **Page** (or a tag). A hub that points at the first 배당 계산 + 단폴과 다폴 posts. Not a fifth topic. |
| 프로토 | **Tag** on 배당 계산 posts. Proto is a *format*, not a pillar. |
| 분석 | **Not a nav word.** Locked meaning is mechanics/math; as a category it will be read as picks. |
| American odds | **Phase 2 post** inside `odds-math`, after the launch set. Not a category. |
| 농구 (NBA/KBL), 롤 | **Phase 2.** Secondary in positioning; do not put in launch nav. |
| 전략 | **Phase 2 / out of Phase 1.** You drop advanced strategy first when time is short. |
| 뉴스 / 경기 일정 / live boards | **Out.** Static hub only. |
| About, 19+ footer, 광고 슬롯 | **Chrome / pages**, not categories. |

Rejected: Misc, General, Other, 팁, 칼럼.
